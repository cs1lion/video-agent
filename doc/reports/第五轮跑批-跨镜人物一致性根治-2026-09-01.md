### 根因（第四轮没追到的）

我修了 gender 在 design-bible 里，但**没修 visual prompt 里"Zhao"被替换成"中年女性"的问题**。

1. design-bible 写"小赵 男 28 岁护士 ✓
2. visual prompt 写"... turning her head to face **Zhao** on the right bench"（用名字）
3. video 模型生成：右边两个中年女性 ❌

**为什么？** visual prompt 里的 "Zhao" 没携带外貌描述，video 模型自由发挥。或者更根本：**prompt 没明确要求"Zhao 必须出现在画面里"**——只说"turning her head **towards** Zhao"，没写"with Zhao in frame on right bench"。

## 2. 第五轮修复（三层防御）

### 2.1 Schema 层：CoCharacter.englishName 字段

```ts
// pi/packages/video-agent/src/clarify/types.ts
export interface CoCharacter {
  name: string;
  description: string;
  voiceId?: string;
  gender?: "male" | "female";
  englishName?: string;  // ← 新增（补遗 §5）
}

// DesignEntity 也加 englishName
export interface DesignEntity {
  ...
  englishName?: string;
}
```

**为什么**：LLM 写 prompt 时常把"小赵" → "Zhao"，"林女士" → "Lin"。如果 design bible 只有中文名，英文转写无法被注入。

### 2.2 Server 层：backfillEnglishNames

```ts
// pi/packages/video-agent-server/src/stages/visual-derive.ts
function backfillEnglishNames(doc, coSpace) {
  // 从 coSpace.characters 复制 englishName 到 design-bible characters
}
```

LLM 生成 design-bible 时不会保留 englishName → 必须在 visual-derive 阶段后处理回填。

### 2.3 Server 层：injectCharacterLooks post-process

```ts
// pi/packages/video-agent-server/src/pipeline.ts (新函数)
function injectCharacterLooks(prompt, characters) {
  // 对每个 character:
  //   - 提取 design 前 100 字符作为外貌短语
  //   - 检测 fingerprint 是否已在 prompt（去重）
  //   - 在 prompt 里找 name/id/englishName 的词边界匹配
  //   - 替换为 "name (外貌短语)"
}

// normalizeShotPrompts 末尾调用
const prompts = script.shots.map((shot, i) => {
  ...
  return { shotId: shot.id ?? ..., prompt: injectCharacterLooks(prompt, designBible?.characters ?? []) };
});
```

**6 个单元测试覆盖**：
- 命中（Lin/Zhao 替换） ✓
- 中文名命中 ✓
- 已注入不重复 ✓
- 不命中无关角色 ✓
- designBible 缺不报错 ✓
- 空 design 跳过 ✓

### 2.4 Prompt 层：强制具体名字

```ts
// pi/packages/video-agent-server/src/prompts.ts shotPromptMessages 要求清单
"4b. 提到其他镜出场角色时，必须使用其在美术设计锚点里的专属英文名或中文名，" +
"避免泛指（如'the young man'），以保持跨镜人物一致性。"
```

**为什么**：光注入外貌短语不够——如果 LLM 写 "young nurse" 这种泛指，注入逻辑无法匹配。强制 LLM 用 "Lin/Zhao/林女士" 这种**具体名**，让 injectCharacterLooks 能工作。

## 6. 教训（沉淀到 MEMORY.md §10）

1. **不要凭单一证据声称"修复完成"**——我用 design-bible + SH01 keyframe 就说"gender fix 完整闭环"，但 SH03/SH04 视频里仍然是错的。
