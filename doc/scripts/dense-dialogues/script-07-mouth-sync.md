# 剧本 G · 嘴不动问题专项测试（visual 与 dialogue 内在矛盾）

> 性质：补遗 §5（"嘴不动"根因）压力测试。
> 用户原话："第一幕画面有台词声音画面却不动嘴是为什么"
>
> 设计意图：故意把"进入/离开动作"和"台词"放在同一镜，看 dubOver 后是否仍嘴不动。

## 一句话需求
5 个镜头，故意制造 visual 与 dialogue 的内在矛盾：人物正在做动作（推门、喝水、放下文件），但同时在说话。video 模型在 reference 跟读失败后会进入 dubOver 模式（嘴动视频保留 + TTS 配音），但如果原视频根本没生成嘴动，dubOver 也救不回来。

## 人物
- **陈姐**（女，35 岁）：酒店大堂经理，雷厉风行，走路带风
- **前台小哥**（男，22 岁）：实习前台，紧张到说话打嗝

## 场景
- 现代酒店大堂，落地玻璃窗外是城市天际线，大堂中央圆形沙发区

## 镜头（5 镜，故意制造 visual-dialogue 矛盾）

### SH01 · 推门进来就开骂
- **audioMode**：dialogue
- **dialogue**：
  - characterId：陈姐
  - lines.zh："你这份简历写的什么鬼？'负责端茶倒水'——你当这是茶馆？"
  - emotion：愤怒
- **visual**：陈姐推开大堂玻璃旋转门大步走进来，高跟鞋踩在大理石地面咚咚响，手里攥着一份简历。
- **预期**：嘴应该动但 visual 是"推门ing"，video 模型大概率不生成嘴型 → **嘴不动 bug**

### SH02 · 喝水打断对方说话
- **audioMode**：dialogue
- **dialogue**：
  - characterId：前台小哥
  - lines.zh："经……经理您消消气，我那天是太紧张了。"
  - emotion：慌张、结巴
- **visual**：前台小哥端着咖啡杯正在喝水，听到陈姐的话被呛到，咳嗽。
- **预期**：嘴在喝水/咳嗽，不在说话 → **嘴不动 bug**

### SH03 · 放下文件才开始讲
- **audioMode**：dialogue
- **dialogue**：
  - characterId：陈姐
  - lines.zh："坐下，听我说完。今天来面试的有 30 个人，你是第 31 个。"
  - emotion：压制怒火
- **visual**：陈姐把简历"啪"地拍在桌上，转身走向沙发区，背对镜头。
- **预期**：嘴应该动但视觉是"转身背对" → **嘴不动 bug**

### SH04 · 转身那一瞬的台词
- **audioMode**：dialogue
- **dialogue**：
  - characterId：前台小哥
  - lines.zh："我……我能不能再问一个问题？"
  - emotion：鼓起勇气
- **visual**：前台小哥从座位上站起来，双手紧紧攥着衣角，低头看自己的鞋尖。
- **预期**：嘴应该动但视觉是"低头看鞋" → **嘴不动 bug**

### SH05 · 两个人都坐着
- **audioMode**：dialogue
- **dialogue**：
  - characterId：陈姐
  - lines.zh："问。但只给你一句话的机会。"
  - emotion：疲惫但留有余地
- **visual**：陈姐坐回沙发靠背上，前台小哥站在她对面，两个人终于都在画面里。
- **预期**：**唯一可能成功的一镜**（两个人都静止坐着，嘴能正常动）

## 旁白
无。

## 美术风格
写实职场，半 overhead 镜头，自然光从落地窗射入。

## 剪辑提示
- 节奏偏快，每镜 4-5 秒
- SH01-SH04 故意制造矛盾（visual 是动作，dialogue 是台词）
- SH05 给一个"正常"的参照（应该能嘴动）
- 全片看视频模型如何在"动作 vs 台词"之间取舍
