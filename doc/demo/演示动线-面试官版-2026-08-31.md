## 0. 环境就绪（30 秒）

1. 双击 `启动演示.cmd` → 两个新窗口（API / UI）保持打开；
2. 浏览器开 `http://localhost:5200`（UI），`http://127.0.0.1:8790/api/health` 可确认 `{"ok":true}`；
3. ⚠️ 8790 被其他会话占用时脚本会**拒绝启动**——按提示 kill 后重跑，不要改端口（UI 代理硬指 8790）。
   旧码服务（当日 07:17 前启动的）必须换掉，否则看不到 category/audioSync 新行为。

## 1. 现场生成动线（约 10 分钟，含两次人工确认）

| 步 | 动作 | 讲什么（工程亮点） |
|---|---|---|
| 1 | UI 提交 brief（用 §2 预验证 brief） | 「brief 是自然语言，下面全自动」 |
| 2 | 团队频道事件流滚动 | 制片人→编剧（**对白密度守卫**：台词镜 <⌈镜数/2⌉ 自动强化重写）→美术指导（风格 bible）→分镜师（**分镜为台词服务**）→配音选角（**24 官方音色分池**，旁白与角色全错开） |
| 3 | 闸门 A：美术设计确认 | 「视频额度昂贵，**未确认不烧钱**」——确认闸门 + 失败图留痕放行 |
| 4 | 闸门 B：关键帧逐镜确认 | 过期镜强制重绘，不放行 |
| 5 | 等待出片 6-8 分钟（填这段时间） | 配额账本 reserve/settle/release + 幂等键；**4 key 双网关并发**（RPM 2→8）；trace JSONL（Run 即 Trace）；降级优于阻断 |
| 6 | 成片播放 + 质检面板 | 七轴逐镜：**audioSync=全语音镜语音就绪率**（确定性口径，同场景旧算法给 40 假象）；textQuality 抓伪中文；三态裁决 ok/warn/fail |
| 7 | 自动质检-修复闭环 | `VIDEO_AGENT_AUTO_REPAIR=1`：fail 或 人物/物理 warn 镜**自动补拍重审**（每 run 一轮 ≤2 镜）；留痕进 report.md 对照表 |
| 8 | 双轮深审（可选加分项） | `node e2e/deep-review.mjs <批次目录>`：两轮独立评审取交集——实测 P1 75/P2 65、confirmed 2/9，**单轮独有 high 被降观察项=误修率下降实证** |

## 4. 主动讲的已知限制（别等提问）

- **伪中文招牌**（如「東庫切蒜館」）：生成模型不可控项——QA 文字轴能抓到并 warn 留痕
  （验证批次 textQuality 70、实抓 2 处），严重度校准按可控问题扣分；
- **人物一致性方差**（跨批次 55↔90）：模型保真度上限；闭环对 fail/人物类 warn 自动补拍改善，
  改善有限时如实留痕不调阈值；
- **词级时间戳字幕**：官方 API 支持已确凿（`timestamp:true` + `return_url/sse` 两约束），
  排期未做——避免同批动字幕链。
