### 技术要点（可复用）
- tsc 路径：monorepo 根 pi/node_modules/typescript/bin/tsc（包内无独立 typescript）。
- queue 产物直接写 assets/<outputName><ext>，重做前先 rename 备份旧文件即可安全覆盖。

## 服务启动（重要端口约定）
- 本项目固定端口：**UI=5200（Vite）/ API=8790（Express）**，见 vite.config.ts 注释（8787/8788 留给其他会话项目；server.ts 默认 8787 直接启动会导致页面 API 全部 502）。
- 正确启动：后端 `cd pi/packages/video-agent-server && PORT=8790 npx tsx watch src/server.ts`；前端 `cd pi/packages/video-agent-ui && npx vite --host`。
- 启动后验证：`curl http://localhost:5200/api/runs/<id>` 应 200（经 Vite 代理）。
